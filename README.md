# НДФЛ.просто

Интерактивный прототип сервиса консультаций по НДФЛ.

## Что уже работает

- солнечный адаптивный интерфейс;
- демонстрационный сценарий оплаты;
- новый четырёхзначный код для каждой консультации;
- форма вопроса и десятисекундное уведомление с кодом;
- ввод кода на сейфе и демонстрация ответа.

## Важное ограничение

Сейчас это демонстрационная версия. Деньги не списываются, вопрос хранится
только в браузере посетителя, а ответ создаётся автоматически. До рабочего
запуска необходимо отдельно подключить ЮKassa, PostgreSQL и защищённый кабинет
консультанта.

## Запуск в Timeweb Cloud Apps

Проект подготовлен для типа приложения **Docker**.

1. Выберите репозиторий `bobosafed-create/ndfl` и ветку `main`.
2. В верхней части формы выберите тип `Docker`.
3. Укажите путь к Dockerfile: `Dockerfile`.
4. Укажите порт приложения: `3000`, если Timeweb запросит его отдельно.
5. Для проверки состояния используйте путь `/`.
6. Добавьте переменную `NEXT_PUBLIC_SITE_URL` с будущим публичным адресом сайта.

Секреты ЮKassa и пароль PostgreSQL нельзя сохранять в репозитории. После
подключения серверной части они должны быть добавлены как защищённые переменные
в панели Timeweb.

## Локальная проверка

Требуется Node.js 22 или новее.

```bash
npm ci
npm run build
npm run start
```
